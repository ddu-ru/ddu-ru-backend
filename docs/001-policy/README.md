# 정책 문서

사람이 합의해야 하는 제품 정책을 정리합니다.

| 문서 | 한 줄 요약 |
|---|---|
| [제품/기능 흐름](./flows/) | 모집글, 참여 신청, 동행 신청/채팅, 나의 여정, 알림 흐름 |
| [홈 메이트 추천 정책](./001-home-mate-recommendation-policy.md) | 추천 대상, 제외 기준, 하루 제공량, 재노출/재생성 정책 |
| [홈 여행방 추천 공통 노출 조건](./002-home-recommendation-eligibility.md) | 공통 필터, 추천별 추가 조건 및 모집 상태 기준 |

## 문서 작성 기준

- 정책 문서는 기획, 디자인, 백엔드, 클라이언트가 함께 확인할 수 있는 표현으로 작성합니다.
- 제품 흐름처럼 정책과 화면 동작이 함께 필요한 문서는 `flows/`에 둡니다.
- DB 테이블명, DTO 이름, SQL, 클래스명처럼 구현자가 참고할 세부사항은 [구현 문서](../004-implementation/)에 둡니다.
- 정책 변경이 구현 변경을 동반하면 정책 문서와 구현 문서를 같은 PR에서 함께 수정합니다.
