# 004. 슈퍼호스트 정책

> 슈퍼호스트 티켓의 지급, 적용, 연장과 게시글 노출 기준을 정의합니다.

---

## 1. 티켓 지급

- 온보딩 설문을 완료한 사용자에게 슈퍼호스트 티켓 3장을 지급합니다.
- 온보딩 보상 티켓 3장은 사용자당 한 번만 지급합니다.
- 각 티켓의 노출 기간은 3일(72시간)입니다.
- 사용하지 않은 티켓만 게시글에 적용할 수 있습니다.

---

## 2. 적용 가능한 게시글

사용자는 본인이 작성한 게시글 중 아래 조건을 모두 만족하는 게시글에만 티켓을 적용할 수 있습니다.

- 삭제되지 않은 게시글입니다.
- 현재 모집 중인 `OPEN` 게시글입니다.
- 현재 모집 인원이 모집 정원보다 적습니다.
- 여행 종료일이 지나지 않았습니다.
- 모집 마감일이 없거나 아직 지나지 않았습니다.

조건을 만족하지 않는 게시글은 슈퍼호스트 관리 화면에 표시하지 않으며 티켓도 적용할 수 없습니다.

---

## 3. 티켓 적용과 기간 연장

- 한 번의 적용에서 게시글 하나에 티켓 한 장을 사용합니다.
- 슈퍼호스트 노출이 없는 게시글은 적용 시점부터 티켓 기간만큼 노출합니다.
- 이미 노출 중인 게시글에 다시 적용하면 현재 최종 종료 시각부터 티켓 기간만큼 연장합니다.
- 연장할 때 남아 있던 노출 기간은 사라지지 않고 새 티켓 기간과 합산됩니다.
- 한 사용자가 여러 게시글에 각각 티켓을 적용할 수 있습니다.
- 사용한 티켓과 각 적용 이력은 보존합니다.
- 최종 확인 시 티켓을 즉시 사용하며, 적용 또는 연장은 사용자가 취소할 수 없습니다.
- 확인 화면에는 적용 기간, 예상 종료 시각, 사용 전후의 보유 티켓 수를 표시합니다.

---

## 4. 슈퍼호스트 관리 화면

관리 화면에는 현재 적용 가능한 내 게시글만 표시하고 아래와 같이 구분합니다.

| 구분 | 표시 정보 | 사용자 동작 |
|---|---|---|
| 적용 중 | 현재 최종 노출 종료 시각 | 연장하기 |
| 미적용 | 슈퍼호스트 미적용 상태 | 적용하기 |

- 적용과 연장은 게시글별로 한 건씩 처리합니다.
- 보유한 미사용 티켓 수를 함께 표시합니다.
- 미사용 티켓이 없으면 `적용하기`와 `연장하기` 버튼을 비활성화합니다.
- 적용 중인 게시글이 여러 개이면 종료 시각이 빠른 게시글부터 표시합니다.

---

## 5. 노출 종료와 취소

- 최종 노출 종료 시각이 지나면 슈퍼호스트 노출이 종료됩니다.
- 게시글을 삭제하거나 `CLOSED` 상태로 변경하면 남은 기간과 관계없이 활성 노출을 취소합니다.
- 모집 마감에 따라 게시글이 자동으로 닫히는 경우에도 활성 노출을 취소합니다.
- 종료되거나 취소된 노출에 사용한 티켓은 복구하지 않습니다.

---

## 6. 홈 노출

- 홈에는 현재 활성 상태이고 참여 가능한 슈퍼호스트 게시글만 표시합니다.
- 같은 게시글을 여러 번 연장했더라도 홈에는 하나의 게시글로만 표시합니다.
- 신고한 게시글은 신고한 사용자에게 노출하지 않습니다.
- 노출할 게시글이 없으면 빈 목록을 제공합니다.
