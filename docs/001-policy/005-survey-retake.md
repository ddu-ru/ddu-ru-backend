# 005. 성향 테스트 재테스트 정책

가입 시 최초 성향 테스트는 추가 테스트 기회를 차감하지 않습니다. 최초 제출 후 대기 없이 재테스트를 1회 할 수 있습니다.

재테스트를 완료하면 마지막 변경일로부터 30일이 지난 날부터 다시 수정할 수 있습니다. 이후에도 수정할 때마다 30일 제한을 새로 적용합니다. 날짜는 한국 시간(KST)을 기준으로 합니다.

예를 들어 11월 2일 가입 테스트 후 당일 바로 재테스트할 수 있습니다. 11월 2일 재테스트를 완료하면 다음 수정 가능일은 12월 2일입니다.

- 기존 가입자 모두에게도 정책 적용 시 즉시 재테스트 기회 1회를 제공합니다. 과거 재테스트 여부와 관계없이 적용합니다.
- 기존 최근 테스트일은 유지하며, 정책 적용 후 첫 재테스트를 완료한 날부터 30일 제한을 시작합니다.
- 답변이 이전과 같아도 정상 제출을 완료하면 기회를 사용합니다.
- 제출이 실패하면 기회를 사용하지 않습니다.
- 동시에 여러 번 제출해도 한 번만 성공합니다.
- 재테스트에는 온보딩 완료 보상을 다시 지급하지 않습니다.

구현과 응답 필드는 [성향 테스트 재테스트 구현](../004-implementation/012-survey-retake.md)을 참고합니다.
