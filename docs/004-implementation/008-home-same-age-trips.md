# 홈 또래 여행 조회

`GET /api/v1/home/same-age-trips`는 로그인한 사용자와 게시글 작성자의 만 나이 차이가
5세 이하인 모집글을 오래된 순으로 최대 30개 후보로 고른 뒤, 그중 무작위 3개를 반환합니다.

## 선정 기준

- `TimeProvider.today()` 기준 공용 `AgeCalculator`로 사용자 만 나이 계산
- 작성자 생년월일 범위는 `today - (사용자 나이 + 6)년` 초과,
  `today - max(0, 사용자 나이 - 5)년` 이하로 DB에서 필터링
- 작성자 프로필 또는 생년월일이 없는 글 제외
- 선호 여행지·게시글 참가자 연령/성별·신청 이력은 추가 필터로 사용하지 않음

기본 노출 조건과 모집 상태·오늘 경계·진행 중 여행 처리는
[홈 게시글 추천 공통 노출 조건](../001-policy/002-home-recommendation-eligibility.md)을 따릅니다.
오래된 30개 후보 제한은 조건 적용 후 DB에서 수행하고, 응답 직전에 무작위 3개를 선택합니다.
따라서 새로고침하면 결과가 달라질 수 있습니다.

## 응답과 상태

- 기존 카드 배열과 필드 유지: 게시글 ID, 제목, 도시명, 시작일, 현재/최대 인원, 대표 이미지
- 이미지가 없으면 `thumbnailUrl=null`, 후보가 없으면 200과 빈 배열
- 사용자 프로필 또는 생년월일이 없으면 404, `BIRTHDAY_NOT_FOUND`
- 비로그인은 401
- 홈 개요의 또래 여행 활성 상태는 기존 로그인 여부 기준 유지

## 검증

DB 통합 테스트로 ±5세의 양쪽 경계, 생일 전후 및 윤년 생일, 오래된 30개 후보 제한과 무작위 3개 선택,
작성자 프로필/생년월일 누락, 사용자 생년월일 누락, 날짜의 오늘 경계,
진행 중 여행, 정원·모집 상태·삭제·본인·신고 글 제외와 카드 매핑을 확인합니다.
컨트롤러 테스트로 로그인 정책, 카드 응답, 생년월일 누락 오류 계약을 확인합니다.

DB 함수로 생년월일을 가공하지 않고 날짜 범위로 비교합니다. 추가 인덱스는 도입하지 않으며,
운영 데이터 규모에서의 실행 계획 및 성능 검증은 별도입니다.
